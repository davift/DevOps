What we're building this course. This is the finished-looking front end for the app we'll use in every module — right now it's a static HTML file with full Create/Read/Update/Delete, but the data lives only in this page's JavaScript memory (refresh the page and it resets to the original four students — nothing is saved to disk or a database yet). Over the next several modules we'll give it a real test suite, a container, a real PostgreSQL database so changes actually persist, a Kubernetes deployment, and CI/CD automation — but this CRUD behavior is exactly what you'll be reproducing against a real database in Module 6.
